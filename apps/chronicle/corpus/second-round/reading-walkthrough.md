## 1. 來源內的連續順序與定位點

依第一輪 [source-pack.json](../first-round/source-pack.json)，A 是《三國志》三傳
同次上傳 revision 發布的同一 stream，章順序為先主傳→周瑜傳→魯肅傳；
B 是另一次上傳的《資治通鑑》卷65 stream。下表分別列 A 的周瑜章與 B 的卷65章，
每表按凍結原文 offset 遞增，兩表不是接在一起的正文。

這些是抽樣定位點，中間仍有完整正文；表中一行不預定一個譯文 block 或 unit，
也不預定相鄰 ordinal。實際正文在各 stream 內按 chapter_index 和譯文 block 順序閱讀，
ordinal 連續遞增。原文 code-point 範圍只用來核對引文，不是譯文的滾動座標。
**正文不按事件年份重排**；倒敘保留原位置，軸不暗示等比例歷史年距。

有明確時間依據的段落須正確標註；僅知年份時顯示該年與「月份未明確」，
整段沒有可用時間時顯示「時間未明確」，不能保留上一段年份。

## 2. 示例跳轉與返回操作

以下是使用者的操作路徑，**不是來源內的連續閱讀順序**。各落點都須換成實際發布的
unit 與 locator，不能用表格行號、第一次字符串命中或事件年份猜位置。

1. 在 A 周瑜章的赤壁 unit 開啟事件預覽；預覽不改 active unit、時間或 context。
2. 若審核已確認同一 canonical Event，從「其他記載」選 B 卷65的 current target。
   顯式切換來源 A→B，保存 A 的返回 locator；B 使用自己的軸與 context，軸不延長 A。
3. 從 B 進入 Event Detail，再返回 B，恢復 B 的原 unit、unit 內位置及焦點。
4. 再返回 A，恢復原赤壁 unit 與位置；跳轉與返回均不重排兩條 stream 的正文。

R2C13 另核對 A 內先主傳與周瑜傳的赤壁位置：兩章均有已確認事件的 current target
時可明確選擇並定位。這是同一 stream 的跨章定位，不是 A→B 的來源切換。

## 3. 桌面（>=1200px）

- 左欄 140–180px 閱讀時間軸：僅連續相同 `year_key` 不重印年標題；
  `period_key` 改變即新建區段，同年換月只新增月標記。未知或回溯後再次出現同年時，
  按實際連續 key 處理，不全局合併（R2C01/R2C02/R2C11）。
- 中欄最大 42rem 連續白話正文：A 內先主傳→周瑜傳→魯肅傳的章界為可見內容邊界，
  **不自動繼承上一章時間**；兩側各自明確且相同的分組才可連續。
  A 與 B 之間則是顯式 stream 切換。
- 右欄 220–260px 當前人物／地點：消費 active unit 的 `context_entities`，
  主要項優先、同類按本段出現順序、按 canonical ID 去重但保留各條來源。
- 旁及的回溯/預敘/背景 span 不參與 narrative_time；整段主敘事回到較早年份時，
  軸仍按本段時間顯示回溯（R2C03/R2C04）。
- 注文（《典略》《江表傳》）完整譯出並可展開原文，保有「某書記載」歸屬；
  來源層次與時間 relation 分開判斷，不一律禁止注文支持事件或 Claim（R2C08/R2C09）。

## 4. 窄屏（<768px）

- 單欄正文；頂部 compact 閱讀欄顯示 active unit 的敘事時間（unknown 原樣表達），
  以及「人物地點」入口。
- 時間軸按需展開為可關閉清單；正文不出現擠壓三欄縮放版。
- 事件預覽以底部面板呈現，關閉不遮最後一段；焦點可見、按鈕至少 44×44 CSS px。

## 5. 事件預覽、跳轉與返回

- 正文事件詞只對 `resolved` span 作可操作入口；`ambiguous`/`unresolved` 明確不確定，
  不冒充唯一事件連結。
- 預覽固定展示：事件名、各來源時間／分歧、簡短已有譯文摘錄或來源說明，
  以及「查看事件／定位發生位置／其他記載」。
- 「定位發生位置」只從 targets 中 `relation=current` 的位置選；多處讓用戶選來源/章；
  無 current 則明確「暫無已收錄發生段落」，**不把第一次字符串命中或最近年份當位置**。
- 跨來源 A→B 保存返回 locator，一鍵返回 A 原赤壁 unit 與 unit 內位置；
  A→B→Event→返回 按棧逐層恢復，不用 `history.back()` 冒充本站導航。
- 預覽開啟不改 active unit，hover/預覽中的回溯事件不切換當前時間；
  實際滾動或主動定位到另一主敘事 unit 時，時間與 context 隨該 unit 更新。
  unknown 顯示未知，不能殘留上一段年份或人物。

## 6. 內容核對與判斷邊界

- 當前段使用本來源時間；canonical 事件聚合年份不覆蓋篇首早年敘事或回溯旁及，
  明確年份也不能一律標為 unknown（R2C01/R2C03/R2C04/R2N03）。
- 跨 stream 切換與同 stream 跨章定位分開核對；同一事件身份及任命/遣軍的歸併
  依審核決定，返回恢復原 unit（R2C05/R2C06/R2C13）。
- 注文/史論須保留歸屬，不冒充原作者的無歸屬斷言或當事人同期發言；
  含注文的 unit 仍可有其他有據 current 事件（R2C08/R2C09/R2C12/R2N02）。
- 周瑜發言中的馬超背景不證明馬超到場；若抽取此戰略判斷，保留周瑜歸屬。
  本卷「以其子超為偏將軍，統其眾」另有直接記載，不能按全卷禁用其 Claim（R2C10）。
- 人物/地點只取 active unit 的有據 context；按 canonical ID 去重但保留角色來源，
  不用顯示名稱自動合併，不推斷長期官職或所有人物所在（R2C07/R2C14）。
- 四章完整內容均可到達，首尾定位點不能代替全文核對；注文內容與歸屬完整，
  不以譯文照抄原文括號或固定 block 數量作完成條件（R2C15）。
- 合成負例（R2N01/R2N02/R2N03）帶 `synthetic=true`，禁止引用為史料發現。

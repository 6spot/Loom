# C3-T17：阅读背景随正文位置自然切换且不干扰连续阅读

## 依据与执行边界

先读[本轮索引](README.md)及本叶涉及的当前规范。任务状态由现用管理工具维护；此处记录需求、接口、依赖和验收，不要求复制最终 PR/merge 元数据。开发阶段可以使用全新测试数据，退役实现无需兼容。有效来源、身份负约束、租约和发布保证仍须保留。

## 当前问题

后端保存的图片需要在读到对应范围时淡淡出现。没有图片、加载失败或位置已离开范围时应回纸底，不让旧事件图一直挂在下一段。

## 前置与文件归属

前置：[C3-T11 / #720](https://github.com/6spot/Loom/issues/720)、[C3-T16 / #725](https://github.com/6spot/Loom/issues/725)。

下列路径均相对 `apps/chronicle/`（明确写出 `apps/`、`.github/` 或 `docs/tasks/` 的除外）；“新增”表示本任务交付，不假设文件已存在。

主改独立背景阅读组件、`HistoryPage.tsx` 的现有 position 接线及专用样式，背景 public API/client 类型。使用 T15 的已保存 binding；不另建 scroll observer 或阅读位置状态机。

## 实施步骤

1. 从当前固定 edition/段落位置读取已启用绑定，复用唯一 reading position。只预加载当前和相邻的已保存背景，不下载全库图。
2. 图片作为独立背景层，pointer-events 关闭，不占正文高度、不影响文字选择或点击。保留中央文字安全区和原纸色/墨色控件。
3. 先加载完成再切换，快速跨范围时丢弃迟到图；无关联、停用、错误回纸底，不能自动找“同名事件”的图顶替。
4. 保留绑定版本/配置一致性；新 edition 不借用旧坐标，变更显示设置只使用已保存 API 响应。
5. 淡入淡出约 160–240ms，prefers-reduced-motion 直接切换。提供关闭背景的阅读设置，关闭后不再预取图片。
6. 文字/控件在最深背景叠加下保持 WCAG AA 对比度，背景切换无 CLS、无正文滚动跳动。

## 验收标准

- [ ] 真实阅读从无图→古代图→无图→近现代图，切换范围与 T16 保存一致。
- [ ] 图片 404/慢网络/快速跳锚点/停用/版本切换不留下错误背景，不清空正文。
- [ ] 开关、reduced-motion、键盘、文字复制和事件点击均正常；主历史与人物往返定位不受影响。
- [ ] 背景不扩大正文 DOM/高度，不发图像生成请求，不整库预加载。
- [ ] PC 实际截图与性能观察证实文字可读、没有布局跳动。

## 验证方式

运行背景范围/迟到加载测试、build/dist 和 history 浏览器场景；用真 binding 和真资源联测。已有通用位置测试通过后只补背景影响的场景。

## 不在本叶内

不做自动配图、正文插图或随时代改变一整套导航控件颜色；手机专门设计不在本叶。
